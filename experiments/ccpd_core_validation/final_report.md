# CCPD 核心机制验证实验报告

## 摘要

本轮实验审查了“合同反事实配对决策学习（CCPD）”的核心模块 M2。研究问题不是 CCPD 能否在某个测试集提分，而是：**联合配对奖励是否提供平衡逐样本训练缺少的、可实际优化的合同敏感性信号。**

最终判断：**REVISE**。

问题本身成立：现有 1.5B 模型在原生工具调用中不能稳定依据合同可满足性切换调用/拒绝，而且 FWCT 存在明确的错误调用—错误拒绝权衡。但 CCPD v1 的 M2 目前不成立为可训练的独立机制：

1. 配对乘积目标和平衡逐样本目标在简化 Logistic 模型中共享相关的共同偏置驻点；“等错误率”不是 M2 独有性质。
2. 配对目标的独特变化是跨侧门控。它会强调“一侧已正确”的配对，却压低“两侧都错”的配对，而后者正是当前小模型最需要学习的状态。
3. E1 中四个模型在严格集的受控 Paired Concordance 均为 100%，说明合同排序信号已经存在；原生 Pair Success 却只有 0%–9.52%，主要断点是信号到动作的集成与操作点，而非完全没有合同比较能力。
4. E2 的真实 8-Rollout 预检中，32 个联合配对奖励全部为 0，B3 零方差组为 100%、有效优势为 0%；相同输出上的 B2 仍有 50% 有效优势。

因此没有启动正式 B0–B3 参数训练。此决定遵循预先规定的训练前检查，不是因工程报错、算力不足或结果不理想而事后停止。

---

## 1. 研究问题

CCPD v1 把调用分数写成：

```latex
s(x,E)=b(x)+d(x,E)
```

其中 `b(x)` 表示请求相关的整体调用倾向，`d(x,E)` 表示合同对决策的影响。方案希望通过同一请求的 E+/E- 配对抵消共同项，并使用：

```latex
J_pair=p_+(1-p_-)
```

直接奖励“两侧同时正确”。

本轮检验三个候选解释：

1. 历史后训练主要移动整体调用倾向；
2. 历史后训练确实改变合同判别；
3. M2 的收益若存在，可能来自联合奖励，也可能来自数据平衡或共享组内标准化。

实际观察、数学结果和未验证假设在下文分开报告。

## 2. E0：理论与梯度审查

### 2.1 解析梯度

定义：

```latex
p_+=\sigma(b+d_+),\qquad p_-=\sigma(b+d_-)
```

平衡逐样本目标与配对目标分别为：

```latex
J_balanced=\frac{1}{2}(p_++1-p_-)
```

```latex
J_pair=p_+(1-p_-)
```

记 `a_+=p_+(1-p_+)`、`a_-=p_-(1-p_-)`，解析梯度为：

```latex
\frac{\partial J_balanced}{\partial b}=\frac{1}{2}(a_+-a_-)
```

```latex
\frac{\partial J_pair}{\partial b}=J_pair(1-p_+-p_-)
```

```latex
\frac{\partial J_balanced}{\partial d_+}=\frac{1}{2}a_+,\qquad
\frac{\partial J_balanced}{\partial d_-}=-\frac{1}{2}a_-
```

```latex
\frac{\partial J_pair}{\partial d_+}=J_pair(1-p_+),\qquad
\frac{\partial J_pair}{\partial d_-}=-J_pair p_-
```

自动微分与解析结果的最大绝对误差为 `6.94e-17`。

### 2.2 共同驻点不是 M2 独有性质

在固定合同差异、只移动共同偏置 `b` 时，两个目标都在：

```latex
p_++p_-=1
```

达到相关驻点，即错误拒绝率等于错误调用率。CCPD v1 把这一性质作为配对乘积目标的核心数学优势，但平衡逐样本目标同样具有该驻点。因此：

- 配对分数差确实形式上抵消 `b`；
- 配对**奖励**并没有因为写成乘积就独占“抵消偏置”的优化性质；
- 公式不同不能单独证明学习机制不同。

若允许 `d_+`、`d_-` 自由变化，两个目标都没有有限内部最大值，都会推动 `p_+→1`、`p_-→0`。

### 2.3 配对目标真正改变的信号

相对平衡目标，配对目标两侧梯度比例为：

```latex
\frac{\partial J_pair/\partial d_+}{\partial J_balanced/\partial d_+}=2(1-p_-)
```

```latex
\frac{\partial J_pair/\partial d_-}{\partial J_balanced/\partial d_-}=2p_+
```

这是一种跨侧门控：

- 当另一侧已经正确时，当前侧梯度可能被放大；
- 当两侧都错误时，两侧梯度同时被压低；
- 当 `p_+=p_-` 时，配对目标可以仅靠把共同调用率校准到 0.5 提高乘积，而不增加合同区分。

因此 M2 可能适合“已具有部分配对成功，只需强化一致性”的后期训练，却可能明显劣于平衡逐样本目标的冷启动。

### 2.4 数值情景

| 情景 | `p+ / p-` | Balanced 合同差异梯度 | Pair 合同差异梯度 | 4 对 Pair 零方差概率 |
|---|---:|---:|---:|---:|
| 高调用 | 0.9 / 0.9 | 0.045 | 0.045 | 68.58% |
| 高拒绝 | 0.1 / 0.1 | 0.045 | 0.045 | 68.58% |
| 两侧接近 | 0.5 / 0.5 | 0.125 | 0.125 | 32.03% |
| 强正确区分 | 0.9 / 0.1 | 0.045 | 0.081 | 43.18% |
| 反向区分 | 0.1 / 0.9 | 0.045 | 0.009 | 96.06% |
| 中等区分 | 0.75 / 0.45 | 0.1088 | 0.1444 | 14.81% |

反向区分是关键反例：模型两侧都错时，M2 的合同差异梯度只有平衡目标的五分之一，且 96.06% 的四对组没有有效优势。

### 2.5 GRPO 分组的独立作用

对 4+4 二元 Rollout 的全部 256 种结果做精确枚举后，得到反向区分状态 `p+=0.1,p-=0.9` 下：

| 方案 | 期望合同对比更新 | 非零组概率 |
|---|---:|---:|
| 两侧分组、逐样本奖励 | 0.0761 | 56.94% |
| 两侧同组、逐样本奖励 | 0.1048 | 56.95% |
| 两侧同组、配对联合奖励 | 0.0078 | 3.94% |

共享混合组本身就改变 GRPO 标准化后的信号，因此 B2 是不可省略的对照。B3 若只优于两侧分组的 B1，不能归因于联合奖励。

### 2.6 代价敏感扩展

理论目标：

```latex
J_\alpha=p_+^\alpha(1-p_-)^{1-\alpha}
```

若不做组内标准化，把成功配对两侧分别赋予 `α` 与 `1-α`，其期望梯度与理论目标方向相同，只差一个正标量。进入混合组标准化后，该精确对应被破坏。

更严重的是：当所有配对均成功且 `α≠0.5` 时，较低权重一侧会得到负优势。例如 `α>0.5` 会对正确的 E- DECLINE 产生负优势，方向与任务目标相反。结论是：首轮实验应删除该扩展，而不是扫描 `α`。

### 2.7 E0 结论

- 独特性质：跨侧门控，而非独有的等错误率驻点。
- 可能优势：模型已有部分配对成功、另一侧正确可作为课程信号时，强化联合一致性。
- 明显风险：双错初态奖励稀疏、全零或全一组、标准化改变理论梯度。
- 决策：不直接训练 v1；先做 E1、E2 和真实 Rollout 信号检查。

## 3. E1：现有模型的调用偏置诊断

### 3.1 数据与协议

从 `capability_probe_v1` 得到 30 个同请求 Valid/Near-miss 配对。审计发现 9 对涉及可选字段或默认行为，因此：

- 主分析：21 对目标字段必填、E- 明确排除全部 Gold 值；
- 敏感性分析：全部 30 对；
- 不使用功能完全不匹配样本。

协议 A 复用历史原生工具调用。协议 B 使用 A/B 标签顺序互换的单 Token 二选一探针：

```text
s = 0.5 * [(logit_A-logit_B)_(A=CALL) + (logit_B-logit_A)_(B=CALL)]
```

该分数只是受控行为代理，不视为原生调用概率。

### 3.2 严格集核心结果

| 模型 | Native Pair Success | Native Valid Call | Native Invalid Call | Probe Pair Success | Paired Concordance | Score Diff | Mean Score |
|---|---:|---:|---:|---:|---:|---:|---:|
| Base | 0.00% | 90.48% | 90.48% | 57.14% | 100.00% | 6.693 | 2.871 |
| FDSRC | 0.00% | 90.48% | 90.48% | 33.33% | 100.00% | 2.196 | 1.339 |
| FWCT | 9.52% | 66.67% | 57.14% | 52.38% | 100.00% | 2.440 | 0.994 |
| FCTW | 4.76% | 80.95% | 76.19% | 61.90% | 100.00% | 3.167 | 1.164 |

FWCT 相对 FDSRC 的任务级配对 Bootstrap 差异：

- Probe Pair Success：`+19.05` 个百分点，95% CI `[+4.76,+38.10]`；
- Pair Score Difference：`+0.244`，95% CI `[+0.110,+0.372]`；
- Mean Decision Score：`-0.345`，95% CI `[-0.423,-0.269]`；
- Native Valid Call：`-23.81` 个百分点；
- Native Invalid Call：`-33.33` 个百分点。

### 3.3 解释

**实际观察：** 所有模型在两个 A/B 标签顺序下都对 21/21 配对正确排序；但原生 Pair Success 极低。

**支持的解释：** FWCT 同时增强了少量合同分数差并降低整体调用分数，属于合同判别与操作点共同变化，而不是纯阈值漂移。

**被否定的强假设：** “FWCT 只移动调用倾向，配对排序没有改善。”

**仍成立的竞争解释：** 受控探针与原生 E- 决策一致率只有 38.10%–61.90%；A/B 顺序在 E- 的绝对决策一致率只有 57.14%–76.19%。Prompt 和输出协议显著影响操作点。

因此，模型并非完全不会读合同；更准确的瓶颈是合同差异信号没有稳定转化为原生调用/拒绝动作。

## 4. E2：合同配对数据的语义可靠性

### 4.1 构造与防捷径

从 100 个既有来源任务开始，只保留：

- 用户明确给出目标值；
- 目标字段必填且无默认值；
- 单工具闭世界；
- enum 或 maximum 能确定排除 Gold；
- E+、E- 从同一工具复制，使用相同编辑算子、措辞和不透明名称。

首轮得到 66 个候选。分层抽查发现一个 `under 30`/`maximum=30` 边界歧义，修正规则后共排除 2 个类似任务，留下 64 个候选，冻结 60 对 v3。

三项表面规则均无法区分 E+/E-：

- 是否出现 Schema 约束：0/60；
- 是否出现限制措辞：0/60；
- 工具名前缀：0/60。

合同序列长度不是平衡控制变量：E- 更长为 25/60，不形成稳定标签规则，但未来正式数据仍应加入更强的表面分类器检查。

### 4.2 人工语义抽查

v3 按约束族×任务类别抽查 14 对，14/14 未再发现歧义。由于样本量小，不能据此声称总体人工一致率达到 95%。

Mock/Schema 检查只证明当前实现的 required/enum/maximum 合同一致性，不能作为真实 API 业务可解性的独立证明。

### 4.3 初始错误

在实际用于预检的 v2 60 对上：

| 模型 | Pair Success | Valid Call | Invalid Call | 格式失败（E+/E-） |
|---|---:|---:|---:|---:|
| Base | 0.00% | 91.67% | 91.67% | 8.33% / 8.33% |
| FDSRC | 0.00% | 90.00% | 91.67% | 10.00% / 8.33% |

任务具有稳定错误和学习空间。v2 后发现两条语义歧义并在 v3 替换，因此这些数值只用于训练前决策，不冒充 v3 正式评测。

## 5. E3：最小受控 GRPO 状态

### 5.1 训练前真实 Rollout 检查

Base 在 8 对训练样本上每侧采样 4 次，共 64 个 Rollout。有效侧奖励要求完整工具名、参数与 Schema 正确；无效侧奖励要求合法拒绝。

| 指标 | 结果 |
|---|---:|
| E+ 调用决策成功 | 84.38% |
| E+ 严格内容成功 | 37.50% |
| E- 正确拒绝 | 0.00% |
| 联合配对成功 | 0.00% |
| B1 E+ 零方差组 | 75.00% |
| B1 E- 零方差组 | 100.00% |
| B2 零方差组 | 50.00% |
| B3 零方差组 | 100.00% |
| B2 有效优势比例 | 50.00% |
| B3 有效优势比例 | 0.00% |

### 5.2 为什么未启动训练

B3 的核心联合奖励在全部 32 个配对上为 0。此时 GRPO 标准化后的优势也全部为 0，M2 不会产生参数更新。相同 Rollout 用 B2 独立奖励仍有非零优势，证明失败来自联合门控而非完全没有监督信息。

如果给 B3 加入内容奖励、逐样本拒绝奖励或课程启动，可能恢复训练，但那会改变待验证的机制。未经新理论定义就这样做，再把收益归因于 M2，会混淆联合奖励与辅助奖励。

因此 B0–B3 正式训练均未执行，Checkpoint 与训练曲线不存在。报告中没有预测或编造训练结果。

## 6. 关键机制分析

### 6.1 联合奖励

联合奖励的独特作用不是“抵消共同偏置”，而是要求另一侧也成功才给当前侧信用。这在后期可能提高联合一致性，在冷启动却切断了最需要的局部纠错信号。

### 6.2 数据平衡

平衡逐样本目标已经具有与配对目标相同的相关共同偏置驻点。当前没有实验证据表明 M2 比 1:1 平衡奖励更优；相反，E0 和预检都显示平衡奖励更稠密。

### 6.3 共享分组

精确枚举证明，B2 的混合组标准化本身会改变更新方向与强度。未来任何 M2 主张都必须比较 B2 与 B3，不能只与两侧分组的 B1 或历史模型比较。

### 6.4 奖励稀疏

M2 在“模型几乎总调用”的初态需要先看到 E- 正确拒绝，才会奖励 E+ 的正确调用；但 E- 正确拒绝恰好为 0%。这造成自举失败。该问题不是增加训练步数能解决的，因为核心梯度为零。

### 6.5 参数与格式错误

E+ 严格内容成功率只有 37.50%，远低于调用决策成功率 84.38%。即使 E- 偶尔拒绝，要求两侧内容同时正确还会进一步稀释奖励。参数生成是第二个独立瓶颈，但本轮没有提前加入 M3，以免混淆 M2。

## 7. 竞争解释与负结果

### 获得支持

- 现有后训练存在整体调用倾向变化。
- FWCT 也有小幅合同分数差改善，因此是混合机制。
- 原生动作与受控合同排序存在显著断裂。
- 高质量合同对可以通过严格筛选构造，但必须有人类语义审计。
- v1 联合奖励在现实初态严重稀疏，并可完全失去 GRPO 优势。

### 未获支持

- “配对乘积目标独有地把操作点固定在等错误率。”
- “FWCT 只是阈值移动，没有任何合同判别改善。”
- “同组配对天然提供比平衡逐样本更强的学习信号。”
- “Schema/Mock 自洽足以证明 Gold 语义可靠。”

### 尚未验证

- Balanced Pair SFT 是否已足以解决 v3 上的原生动作问题。
- B1 与 B2 的训练后泛化差异。
- 一种不依赖联合成功门控的稠密配对目标能否优于 B2。
- v3 之外的未见工具家族、未见约束和外部 Benchmark 泛化。

## 8. 与已有方法的关系

以下关系基于 CCPD v1 提供的文献材料，本轮没有重新复现外部论文：

- **ToolRL / Tool-N1 类逐样本奖励**：当前结果不证明它们足以解决合同拒绝，但说明其稠密局部反馈在冷启动阶段可能比联合成功奖励更可优化。
- **RLVP 与拒绝惩罚**：能直接给 E- 错误调用负反馈，但可能移动整体调用倾向；需要同时监控 E+ 调用率与配对排序。
- **AgentAbstain 的配对评估**：Pair Success 仍是有价值的评测指标，但“配对评测指标”不自动推出“乘积式训练奖励”。
- **Behaviorally Calibrated RL**：其核心是操作点与错误代价；E1 说明校准视角与合同排序视角都需要，不能互相替代。
- **配对 GRPO / 共享环境工作**：E0 复现了一个重要警告，共享组既可能改变方差，也可能改变标准化后的方向；必须用 B2 隔离分组效应。

当前创新空间更接近“合同排序信号如何稳定转化为原生动作，同时保留稠密信用分配”，而不是现有 `p+(1-p-)` 乘积奖励本身。

## 9. 最终研究决策：REVISE

### 为什么不是 GO

- M2 的核心独特性论证被 E0 削弱；
- E1 显示模型已有强配对排序，旧叙事不准确；
- B3 在真实预检中没有任何有效优势，无法开展可归因训练。

### 为什么暂时不是 NO-GO

- 动态合同下的原生调用/拒绝问题真实存在；
- E2 表明可以构造严格配对并观察到稳定错误；
- 尚未实测 Balanced Pair SFT、B1、B2 是否已经充分解决问题，因此不能断言整个合同条件化学习方向没有价值。

### 建议的最小下一步

1. 暂停 CCPD v1 的 B3 和 M3，不扫描 `α`，不扩展模型规模。
2. 先在 v3 或独立扩展集上做一次低成本 Balanced Pair SFT；若已解决主要问题，当前 M2 直接 NO-GO。
3. 若仍需 RL，只比较 B1 与 B2，确认共享混合组是否有独立价值。
4. 只有在重新推导出“双方都错时仍有稠密梯度、且相对 B2 有独立作用”的配对原则后，才定义新的 B3。新目标必须先通过 E0 同等级别的解析与 Rollout 预检。

这不是给 M2 增加补丁，而是要求重新定义它的学习原则。
