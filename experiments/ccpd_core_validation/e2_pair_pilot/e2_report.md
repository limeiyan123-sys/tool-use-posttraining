# E2：合同配对 Gold 可靠性与训练信号 Pilot

## 1. 生成结果

来源为既有 FCTW 训练来源的 100 个基础任务。生成器不直接复用旧 E10/E01，而是从同一个合法工具复制两侧合同，并对同一目标字段施加同类型约束：

- E+ 的约束包含用户明确要求的 Gold 值；
- E- 的约束排除该值；
- 两侧均有约束、相同限制措辞、等长不透明工具名和单工具闭世界；
- 只保留目标字段必填、无默认值、Gold 值在请求中有直接文本证据的任务。

首轮机械筛选：

| 结果 | 数量 |
|---|---:|
| 来源任务 | 100 |
| 初始合格 | 66 |
| 目标字段可选而舍弃 | 16 |
| 缺少直接请求证据而舍弃 | 18 |

第一次分层语义抽查发现，`under 30 minutes` 与来源 Gold `time=30` 存在开闭区间歧义。修正规则后，额外排除 2 个严格上界歧义任务，剩余 64 个合格候选；从中按固定哈希顺序冻结 60 对：

- train/dev/test：40/10/10；
- enum/numeric_range：33/27；
- simple_python/multiple/parallel/parallel_multiple：20/17/20/3。

v3 数据哈希：`e5788137bae54d0c13089023e4a0e36eaa971f9ac03e03ec1f97b3f7b82e549f`。

## 2. Gold 验证范围

自动检查能够证明：

1. E+ 的冻结 Gold 调用通过本 Pilot 使用的 required/enum/maximum 合同子集；
2. 同一调用在 E- 被拒绝；
3. 请求、工具功能和非目标字段保持不变；
4. 合同内没有第二个工具绕过目标约束；
5. “有无约束”“有无限制措辞”“工具名前缀”三个编辑痕迹规则对 60 对都没有区分力。

自动检查不能证明外部 API 的真实业务语义。它与生成器共享合同定义，因此只是内部一致性验证，不是独立语义证明。

v3 按约束族与任务类别分层抽查 14 对，14/14 未再发现歧义。该样本量不足以证明总体标签一致率达到 95%；因此当前结论是“Pilot 质量足以继续机制预检”，不是“M1 已获得论文级自动 Gold 可靠性”。

## 3. v2 原生模型错误分布

Base/FDSRC 原生生成在规则修订前的 v2 60 对上运行，结果按原哈希保留：

| 模型 | Pair Success | Valid Call | Invalid Call | Valid INVALID | Invalid INVALID |
|---|---:|---:|---:|---:|---:|
| Base | 0.00% | 91.67% | 91.67% | 8.33% | 8.33% |
| FDSRC | 0.00% | 90.00% | 91.67% | 10.00% | 8.33% |

两模型均没有产生一次“E+ 调用且 E- 拒绝”的完整配对成功。有效侧与无效侧几乎同率调用，说明任务存在充足的决策学习空间；错误不是由无效侧过难、模型普遍拒绝造成的。

这些结果不能作为 v3 的正式评测值：v2 后续发现 2 个严格边界歧义并被替换。由于结论是 0/60 Pair Success 且用于是否启动训练的粗粒度诊断，没有为美化结果而重跑；未来正式训练必须使用 v3 或新的独立数据。

## 4. 训练前 8-Rollout 奖励预检

从 v2 训练分区固定取前 8 对，Base 每侧采样 4 次，温度 0.8、top-p 0.95、最大 96 Token。有效侧奖励要求工具名、Schema 和完整参数与 Gold 一致；无效侧要求合法拒绝。

| 指标 | 结果 |

| E- 正确拒绝率 | 0.00% |
| E+ 严格内容成功率 | 37.50% |
| E- 内容成功率 | 0.00% |
| 联合配对成功率 | 0.00% |
| B1 E+ 零方差组 | 75.00% |

该结果比根据确定性调用率估算的约 72.8% 全零概率更严重：在实际 32 个配对 Rollout 中，B3 联合奖励全部为零。相同生成结果上的 B2 仍然提供非零组内优势，因此问题来自联合成功门控，不是数据本身完全没有奖励信息。

## 5. E2 决策

**不进入当前定义的 E3 训练。** 原因不是工程故障或 GPU 不足，而是 B3 在训练初态没有有效优势。此时直接启动 30–50 步训练，参数不会从核心联合奖励获得学习信号；加入额外奖励再训练会改变待验证机制，无法归因于 M2。

E2 支持以下两个结论：

1. 可低成本构造一批比旧数据更严格的合同对，但自动 Gold 仍必须经过语义抽查，Schema 自洽不能替代语义正确；
2. 当前配对乘积采样奖励在模型最需要学习的“几乎从不拒绝”初态下恰好最稀疏，这是 CCPD v1 的核心优化缺陷。
