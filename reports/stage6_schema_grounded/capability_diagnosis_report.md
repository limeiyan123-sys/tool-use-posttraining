# Stage 6 Capability Diagnosis Report

## 实验设置

- 数据：30 个独立基础意图，每个意图包含 Valid、Near-miss、功能不匹配三个单工具样本，共 90 条。
- 约束：enum、numeric range、训练未见的 string pattern，以及功能不匹配。
- Probe A：原工具调用协议，直接调用或拒绝。
- Probe B：显式 JSON 兼容性判断，同时要求定位违反约束。
- 解码：固定贪心解码；五个模型使用完全相同的数据与提示。

## 诊断结论

1. 功能不匹配不是主要瓶颈。除 Zero-shot 外，所有后训练模型在原协议下均达到 96.67%–100%。
2. Near-miss 是关键断点。Zero-shot、LoRA、FDSRC 在原协议均为 0%，FCTW 仅 13.33%；但显式兼容性判断达到 96.67%–100%。模型能提取冲突信号，却没有稳定将其转化为拒绝行动。
3. FWCT 将 Near-miss 原协议准确率提高到 46.67%，证明训练分布可以影响能力门控；其 Valid 准确率同时降至 70%，与已有 Distractor 错误拒绝现象一致。
4. FCTW 将 Valid 恢复到 86.67%，却把 Near-miss 降到 13.33%。这说明四象限平衡没有形成稳定的能力判别边界，而是在调用和拒绝倾向之间重新折中。
5. 显式协议对 Valid 存在明显过度拒绝，且字段/约束精确定位很弱。因此不能把高 Near-miss 二分类准确率解释为完整的 Schema 语义绑定能力。
6. 当前主要瓶颈是 Capability-Aware Decision Integration；其次是可验证的字段级绑定。参数生成仍影响端到端结果，但不能解释 Substitution 的系统性失败。

## 证据边界

- Probe 使用历史诊断来源，不作为新方法的独立最终泛化证据。
- 显式提示改变了任务形式，其结果只能证明信号可被提示激活，不能证明模型形成了稳定内部模块。
- 约束定位采用严格字符串标签；Field 与 Constraint Type 另行报告，未使用模糊匹配美化结果。
